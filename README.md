# 🧠 QuizVerse - Interactive Quiz Game

QuizVerse is an interactive quiz web application designed to test users' knowledge through multiple-choice questions and instant score evaluation.

## 🚀 Features

- Multiple Choice Questions
- Score Calculation
- Question Navigation
- Answer Validation
- Result Screen
- Restart Quiz Option
- Responsive Design

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

```
│
├── index.html

└── script.js
```
